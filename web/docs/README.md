# Dify Web 前端代码解析文档

本文档旨在对 Dify Web 前端代码 (`web/`) 进行全方位的深度解析，帮助开发者快速理解项目架构、核心逻辑和业务实现细节。

## 目录结构说明

文档目录结构与代码模块结构保持逻辑上的一致性，便于索引和查阅：

*   **`images/`**
    *   存放文档中引用的所有图片资源（如流程图、架构图、截图等）。

*   **模块化解析文件夹**
    *   针对项目中的大模块建立独立的文件夹进行详细解析。
    *   **`service/`**: 服务层代码解析，涵盖 API 请求封装 (`fetch.ts`, `base.ts`)、SWR Hooks 封装及各业务领域的 Service 实现。
    *   **`signin/`**: 登录模块详细解析。
    *   **`signup/`**: 注册模块详细解析。
    *   *(后续将根据需要添加更多模块文件夹，如 `app/`, `components/` 等)*

*   **根目录文档**
    *   **`README.md`**: 本文档，提供文档概览和导航。
    *   **`Dify Web 前端登录与鉴权.md`**: 全局登录与鉴权机制的整体分析。
    *   **`入口文件layout解析.md`**: Next.js 应用入口、Layout 结构及全局 Context 的解析。
    *   **`本地开发指南.md`**: 前端环境搭建与开发调试指南。

## 贡献指南

如果您在阅读代码过程中有新的发现或补充，欢迎按以下规则贡献文档：
1.  **图片资源**：请将图片放入 `images` 文件夹。
2.  **模块解析**：如果是特定业务模块的解析，请在根目录下创建对应文件夹（如果不存在），并在其中添加 Markdown 文档。
3.  **全局分析**：如果是涉及全局架构或通用机制的分析，请直接在根目录下创建 Markdown 文档。
